    Evidence and limits
    • Every company and field is fictional. Example URLs are labels for fixtures and are never fetched.
    • The evidence date check uses a fixed reference date of 17 October 2026 for reproducibility. It checks consistency with supplied records, not the truth of real-world claims.
    • Approval uses a payload digest and a synthetic actor. There is no authenticated user or cryptographic signature.
    • The ledger is in memory. It has no concurrency, crash-recovery or cross-restart guarantee.
    • The Python test suite checks rejection paths, approval binding, bounded retries and duplicate-write prevention. It is not an independent security audit.
